# 독서 완료 화면 인용문 — 초기 50개

오늘의 독서를 마치면 축하 문구 대신 이 중 한 문장이 무작위로 뜬다. 앱이 읽는 데이터는
`data/reading-quotes.json`이고, 이 문서는 그 검토표다.

## 고른 방법

- **원문 대조:** 후보마다 Project Gutenberg 공개 원문을 받아, 따옴표 모양·줄바꿈·이탤릭 표시·대소문자만
  걷어 내고 원문 문장이 글자 그대로 있는지 확인했다(`npm run check:quotes`). 확인되지 않은 문장은 넣지 않았다.
- **번역:** 기존 번역본을 옮기지 않았다. 모두 원문에서 새로 옮긴 자체 번역이라 번역권 문제가 없다.
- **저작권:** 모두 작가가 1962년 이전에 세상을 떠난 작품이다. 국내에서는 2013년 보호기간 연장(70년) 전에 50년이
  지나 이미 만료된 작품들이라 원작 보호기간이 끝났다. 다만 상업용 앱이므로 출시 전에 법률 검토를 한 번 받아 두기를 권한다.
- **분위기:** 성공·노력을 외치는 명언이나 교훈을 직접 가르치는 문장은 빼고, 소설 속에서 우연히 만나는 대사와 서술을 골랐다.
