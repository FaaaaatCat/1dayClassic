# 하루서점 — 앱 기획 브리핑 (GPT 전달용)

> **이 문서를 읽는 AI에게**
> 이 문서는 개발 중인 모바일 앱 「하루서점」의 현재 상태를 설명한다. 작성자는 이 앱의
> **기획적인 도움**(기능 우선순위, 사용자 경험, 수익 모델, 출판사 제안 방향, 빠진 것 찾기)을
> 받고 싶어 한다. 코드나 구현 방법보다는 **무엇을, 왜, 어떤 순서로** 만들지에 대해 조언해 주기를
> 바란다.
>
> - 모든 내용은 2026-10-12 기준 실제 앱 코드와 데이터에서 읽어 낸 사실이다.
> - `(확인 필요)`가 붙은 항목은 코드에 근거가 없어 **작성자가 아직 정하지 않은 것**이다.
>   이 부분은 추측으로 채우지 말고, 필요하면 작성자에게 질문하거나 선택지를 제안해 달라.
> - 이전 버전 문서(`docs/1dayClassic-기획-브리핑.md`, 9월 7일 기준)는 그 뒤로 이름·콘텐츠·화면이
>   많이 바뀌어 이 문서가 대신한다.

---

## 1. 한 문장으로

**아침 알람을 끄면 그날 읽을 책 한 쪽이 펼쳐지는 앱.** 고전·교양서를 하루 한 편씩, 카드를
넘기듯 읽고 퀴즈로 복습한다.

앱 안에서 쓰는 소개 문구 세 줄(첫 실행 인트로):
1. 좋은 책을 하루치로 잘라 드립니다
2. 까먹지 않게 매일 알람을 드려요
3. 퀴즈로 까먹지않게 복습까지 챙겨요.

---

## 2. 지금 이 앱의 위치

- **출판사에 보여 주기 위한 데모 앱**이다. 실제 스토어 출시용이 아니다.
- 원래는 실존 출판사(유유출판사)의 도서로 만들었지만, 데모로 넘기기 위해 **저작권이 끝난 고전과
  자유 이용 저작물로 콘텐츠를 모두 바꿨다.** 서점에 보이는 출판사 넷(밑줄사이·낮은문장·첫자리·
  한밤서가)은 **가상의 출판사**이고, 저자 표기도 "○○ 편집부 엮음"으로 통일했다(실존 인물과 겹치지
  않게).
- 앱 이름: **하루서점** (설치 아이콘 이름도 하루서점). 저장소 이름은 예전 이름인 1dayClassic이다.
- 플랫폼: **Android 전용** (알람을 직접 만든 네이티브 모듈이 Android에만 있다).
- 결제·회원가입은 **모양만 있고 동작하지 않는다** (데모용). 가입 시트의 '데모계정으로 계속하기'로
  들어간다.
- 서버 없음. 모든 기록은 기기 안에만 저장된다.

`(확인 필요)` 이 데모를 받는 출판사에 무엇을 제안하려는가 — 출판사용 앱을 만들어 주는 것인지,
여러 출판사의 책을 모으는 플랫폼인지, 특정 책 시리즈의 부가 서비스인지.

## 3. 핵심 아이디어

**알람은 매일 반드시 보는 화면이다.** 그 자리에 읽을 것 한 쪽을 놓는다. 사용자는 "공부하려고
앱을 여는" 것이 아니라, 매일 이미 보는 화면에서 책을 만난다.

이 발상이 앱 곳곳에 반영되어 있다.
- 알람 화면의 큰 버튼은 '끄기'가 아니라 **'공부하기'**다. 누르면 그날의 한 편이 바로 열린다.
- 폰이 잠긴 상태에서도 잠금을 풀지 않고 오늘의 한 편이 뜬다 (알람 앱 '알라미'와 비슷한 경험).
- 알람이 여는 책은 사용자가 서점에서 고른 책을 따라간다.

화면 설계에서 반복되는 원칙:

| 원칙 | 예 |
|---|---|
| 하루에 한 쪽 | 하단 탭바가 없다. 늘 떠 있는 탭바는 "갈 곳이 많다"는 인상을 주기 때문 |
| 한 화면은 한 가지만 말한다 | 홈에는 지금 읽는 책 한 권만 서 있다 |
| 종이처럼 | 그림자 대신 가는 선으로 구역을 나눈다 |
| 원본에 없는 것은 지어내지 않는다 | 원본에 날짜가 없는 책은 앱에서도 날짜를 표시하지 않는다 |
| 포인트 색은 한 화면에 하나 | 주황(#FF4704)을 한 화면에 한 곳만 쓴다 |

## 4. 사용자 흐름

### 4-1. 첫 실행 (온보딩)

```
인트로 3장 → 가입 시트 → 질문 6단계 → 홈(환영 창)
```

1. **인트로 3장** (어두운 화면, 장마다 움직이는 그림 하나)
   - 반으로 갈리는 종이 — "좋은 책을 하루치로 잘라 드립니다"
   - 울리는 자명종 — "까먹지 않게 매일 알람을 드려요"
   - '퀴즈' 위로 떠오르는 말풍선 ?, !, ✓ — "퀴즈로 까먹지않게 복습까지 챙겨요."
   - 마지막 장의 '하루서점 시작하기' 또는 '로그인하기'를 누르면 가입 시트가 뜬다.
2. **가입 시트** — '데모계정으로 계속하기' / '회원가입'(동작 안 함).
3. **질문 6단계**
   1. 관심 분야 — 3개 이상 고르기
   2. 독서 빈도 — 거의 읽지 않아요 / 한 달에 1~2권 / 일주일에 1권 / 일주일에 2권 이상 / 매일 읽어요
   3. 독서 목적 — 새로운 지식 획득 / 여가를 위한 재밌는 이야기 탐독 / 마음 수양
   4. (책 추천 중 로딩 화면) → 처음 읽을 책 1권 고르기
   5. 매일 알림 시각 정하기 (알림 미리듣기 30초 가능)
   6. 권한 승인 — 알림 / 정확한 알람 / 전체 화면 알림
4. **홈 + 환영 창** — "회원님께는 10화 무료보기를 제공합니다" 같은 환영 문구가 뜬다.

- 고른 책은 홈의 '지금 읽는 책'이 되고, 마이페이지의 '읽을 예정인 책'에도 담긴다.
- 관심 분야·독서 빈도·독서 목적 답은 **아직 어디에도 쓰이지 않는다** (저장도 안 함). 추천에 쓸
  재료로 모으는 자리만 만들어 두었다.
- 독서 목적 질문의 안내 문구가 독서 빈도와 같은 "얼마나 자주 읽는지 궁금해요"로 되어 있다.
  `(확인 필요)` 독서 목적에 맞는 안내 문구.

`(확인 필요)` 환영 창의 '10화 무료'와 실제 무료 범위(아래 7장, 책마다 2화)가 다르다. 어느 쪽이
의도인지.

### 4-2. 매일 아침 (알람 → 공부)

```
알람 시각
 → 폰이 잠겨 있거나 화면이 꺼져 있으면: 전체화면 알람 (시계, 날짜, 책 표지, 배경 사진)
 → 폰을 쓰는 중이면: 화면 위에 알림 배너 + 알람 소리
 → '공부하기'(끄기)를 누르면 오늘의 한 편이 열린다. 잠긴 폰이면 잠금을 풀지 않은 채로.
 → 카드 넘겨 읽기 → 퀴즈 → 공부 리포트
```

- 스누즈도 있다.
- 알람이 울리는 동안 앱 아이콘을 누르면 홈이 아니라 알람 화면이 뜬다.
- 잠금 상태에서 열린 경우 뒤로가기가 막히고, 홈 버튼을 누르면 잠금화면으로 돌아간다.

### 4-3. 평소 (홈)

- **어두운 화면 한가운데 지금 읽는 책 한 권**이 세워져 있고, 그 아래 진행 줄(○p 읽음 / 총 ○p),
  그 아래 **문 셋: 목차 · 읽기(주황 원) · 리포트**.
- 위쪽에는 하루 서점 버튼, 알람 시각 버튼, 마이페이지 버튼.
- 읽기 버튼 위 말풍선이 무엇을 열지 알려 준다: "무료로 첫화보기" / "이어 읽기 : 제n화" /
  "1화부터 다시 읽기".
- '다 읽었다'의 기준: 퀴즈를 다 풀었거나, '다음 화 읽기'를 눌렀거나, 마지막 장까지 갔을 때.

## 5. 화면과 기능

### 5-1. 오늘의 공부 (읽기 화면) — 앱의 중심

한 편은 **카드 여러 장**으로 나뉜다: 표지 장 → (인용 장) → 본문 장들 → 맺음 장.
보통 한 편이 15장 안팎이다 (표지 1 + 인용 1 + 본문 12 + 맺음 1). 본문은 한 장에 한 문단이고
문장을 중간에서 자르지 않는다.

**보기 방식 3가지** (마이페이지 > 책 보기 설정에서 고름)

| 방식 | 모습 |
|---|---|
| 책 넘김 효과 | 왼쪽 모서리를 축으로 종이가 뒤집히듯 넘어간다. 넘긴 장이 왼쪽에 쌓인다 |
| 카드로 보기 | 넘김 효과 없이 카드가 바로 바뀐다. 카드가 더 크다 |
| 스크롤 보기 | 카드 없이 화면 전체가 종이. 위에서 아래로 쭉 읽는다 |

**그 밖의 기능**
- **자동으로 읽기(TTS 낭독)** — 문장 단위로 읽고 읽는 자리를 표시한다. 배경음악을 함께 깐다.
  목소리(여자/남자)와 '열자마자 자동으로 읽기'를 설정할 수 있다.
- **유튜브 재생기** — 클래식 책은 그날의 곡을 앱 안에서 바로 듣는다. 스크롤 보기에서는 위쪽에
  화면 폭으로 붙박여 있다.
- **책갈피** — 장 단위로 꽂는다.
- **퀴즈** — 한 편에 4지선다 3문제. 맺음 장의 '퀴즈 풀기'로 들어간다.
- **감상 노트(메모)** — 기능은 있지만 지금은 **화면에서 버튼을 잠시 숨겨 두었다.**
- **책 배경** — 라이트(밝은 종이) / 다크(어두운 종이).
- **글자 크기** — 작게 / 중간 / 크게.
- 무료 범위의 마지막 화를 끝내면 **책 구매 안내**가 뜬다 (6장 참고).

### 5-2. 목차 (다크)

- 맨 위에 **성적 현황**: 진행도(읽은 쪽 / 전체 쪽, %)와 오답률(틀린 문제 / 푼 문제, %).
- 그 아래 화 목록. 읽은 화에는 '2/3 정답' 같은 성적, 읽을 수 있는 화에는 '퀴즈 풀기', 잠긴 화에는
  자물쇠.
- 정렬: 첫장부터 / 최신순.

### 5-3. 퀴즈와 공부 리포트

- 퀴즈: 보기를 고르면 정답·오답과 해설이 바로 보인다. 정답은 초록, 오답은 빨강.
- 공부 리포트: "Keep it up!" + 연속 공부 일수 + 날짜 + 책 이름 + '다음 화 읽기'.
  연속 일수는 **지금 7일로 고정된 값**이다 (실제로 세지 않음).

### 5-4. 하루 서점

- 108권 전시: 학습 콘텐츠가 있는 9권 + 표지와 서지 정보만 있는 전시용 책 99권.
- 메인: 배너(기획전), 분야 바로가기, **'지금 바로 읽을 수 있는 책'**, **'새로 나온 책'** 섹션.
- 기획전 3개: "가볍게 시작하는 외국어", "곁에 두고 읽는 동양 고전", "글을 쓰는 사람에게".
- 목록 / 검색(최근 검색어) / 책 상세.
- 책 상세에서 '읽기'를 누르면 그 책이 홈의 '지금 읽는 책'이 되고 알람도 그 책을 연다.
  '내 서재'에 담기와 빼기도 여기서 한다.
- 구매 버튼은 있지만 동작하지 않는다 (데모).

### 5-5. 마이페이지 (다크)

- **읽을 예정인 책** (담은 책들, 진행률) · **완독한 책**
- **책 보기 설정** — 책 배경 / 책 넘기기 방식 / 글자 크기
- **배경음악 설정** — 고요한 / 평화로운 / 경쾌한 / 없음. 줄마다 '미리듣기'.
- **TTS 설정** — 보이스(여자/남자, 미리듣기) / 자동읽기(켜기/끄기)
- 프리미엄 멤버십 배너 ("평생 광고 없이 쾌적하게 독서하세요") — 누를 곳만 있고 동작 없음.
- **권한 관리**, **계정 관리**(로그아웃·회원탈퇴, 동작 없음)
- **책 리포트**(책마다): 독서 진도, 퀴즈 정답률, 책갈피 수, 독서 노트 수, 마지막으로 읽은 날.
  여기서 **틀린 문제**, **책갈피**, **독서 노트** 모음으로 들어간다.

### 5-6. 알람 설정

- 시각(오전/오후·시·분 휠), 켜기/끄기, 반복 요일.
- 알람음은 기기의 기본 알람음.

## 6. 콘텐츠

### 6-1. 학습할 수 있는 책 9권

| 책 | 가상 출판사 | 분야 | 한 편의 표제 | 편수 |
|---|---|---|---|---|
| 명심보감 | 밑줄사이 | 고전 / 동양고전 | 한자 원문 + 독음 + 뜻 | 20 |
| 천자문 | 밑줄사이 | 한자 | 한 편에 4글자 (훈·음) | 10 |
| 논어 | 낮은문장 | 고전 / 한문 | 한문 원문 + 토 + 번역 | 10 |
| 채근담 | 낮은문장 | 고전 / 동양고전 | 글 제목 + 인용문 | 10 |
| 명상록 | 첫자리 | 철학 / 스토아 | 글 제목 | 10 |
| 라틴어 | 첫자리 | 라틴어 / 고전어 | 라틴어 + 발음 + 뜻 | 10 |
| 영어 속담 | 한밤서가 | 영어 / 언어 | 영어 표현 + 뜻 + 예문 | 10 |
| 글쓰기 | 한밤서가 | 글쓰기 / 문장 | 글 제목 + 인용문 | 10 |
| 클래식 | 한밤서가 | 클래식 / 음악 | 곡 제목 + 작곡가 (+ 유튜브) | 11 |

- 모두 합쳐 **101편**. 한 편마다 본문 12문단 안팎, 퀴즈 3문제.
- 정가 표시: 명심보감 10,000원, 나머지 9,000원 (데모용 표시).
- 명심보감·천자문처럼 원본이 날짜별로 구성되지 않은 책은 날짜를 보여 주지 않는다.

### 6-2. 표지

- 표지는 그림 파일이 아니라 **코드로 그린다**. 책마다 종이색, 글자색, 무늬, 출판사 마크를 갖는다.
- 콘텐츠 사진은 Unsplash 사진과 사진가 크레딧을 쓴다.

## 7. 수익 모델 (지금 들어 있는 것)

- **책마다 앞쪽 일부만 무료**: 전체 편수의 10%, 최소 2편. 지금은 모든 책이 2편 무료다.
- 무료 마지막 편을 끝내면 **책 구매 안내**가 전체 화면으로 뜬다.
  - "무료로 열린 2편을 모두 읽으셨어요"
  - "뒷 내용이 더 궁금하시다면 이 책을 만나 보세요"
  - 『책 제목』, 저자, 태그, 쪽수
  - "이 책에는 아직 잠긴 n편이 남아 있어요"
  - [9,000원 · 책 구매하기] → 서점의 책 상세로 이동 / [다음에 볼게요]
- 마이페이지에 '프리미엄 멤버십' 배너가 있다 (광고 제거를 내세움). 동작하지 않는다.
- 전면 광고 화면(10초 뒤 닫힘)이 만들어져 있지만 **어디에도 연결되어 있지 않다.** 예전에는
  알람을 끄면 광고를 거쳤는데, 잠금화면 위에서 건너뛸 수 없는 광고가 되어 뺐다.

`(확인 필요)`
- 무엇을 파는가 — 앱 안의 책 한 권 단위 구매 / 구독 / 종이책 구매로 연결 / 광고 제거 멤버십?
- 구매 안내가 결국 어디로 보내야 하는가 — 앱 안 결제인가, 출판사 서점인가.
- 출판사와의 수익 배분 구조.
- 광고를 붙일 것인가, 붙인다면 어디에.

## 9. 만들어진 것 / 아직 아닌 것

첫 실행 흐름 · 홈 · 목차(성적 현황) · 읽기 3방식 · TTS 낭독 + 배경음악 · 유튜브 인앱 재생 ·
퀴즈 + 틀린 문제 모음 · 책갈피 · 노트(숨김 중) · 책 리포트 · 하루 서점(108권, 기획전, 검색) ·
마이페이지와 설정들 · 네이티브 알람(전체화면, 잠금화면 위 읽기, 배너, 스누즈) · 구매 안내 화면

### 아직 아닌 것
- 결제, 회원가입, 로그인 (모양만 있음)
- 서버와 계정, 기기 간 동기화
- 연속 공부 일수 실제 계산 (지금 7일 고정)
- 온보딩 답(관심 분야·빈도·목적)을 추천에 쓰기
- 광고
- iOS
- 콘텐츠 분량: 책마다 10~20편. 실제 책 한 권 분량이 되려면 훨씬 많이 필요하다.

## 10. 작성자가 아직 정하지 않은 것 (`확인 필요` 모음)

조언할 때 이 항목들을 함께 고려해 주거나, 선택지를 제안해 주면 좋다.

1. 이 데모로 출판사에 무엇을 제안하는가 (출판사 전용 앱 / 여러 출판사 플랫폼 / 책의 부가 서비스).
2. 타깃 사용자는 누구인가 (코드에는 페르소나 정의가 없다).
3. 수익 모델 — 무엇을 팔고, 어디서 결제하고, 출판사와 어떻게 나누는가.
4. 무료 범위 — 환영 창의 '10화 무료'와 실제 '책마다 2편 무료' 중 무엇이 의도인가.
5. 광고를 붙일 것인가.
6. 온보딩 질문(관심 분야, 독서 빈도, 독서 목적)의 답을 무엇에 쓸 것인가.
7. 감상 노트를 다시 보이게 할 것인가, 다른 형태로 바꿀 것인가.
8. 성공을 무엇으로 측정할 것인가 (매일 알람에서 공부로 넘어간 비율, 연속 일수, 구매 전환 등).
9. 서버·계정을 언제 도입할 것인가.
10. iOS를 지원할 것인가 (지금 핵심인 알람 경험은 Android에서만 가능하다).

## 11. 이런 도움을 받고 싶다 (질문 예시)

- '알람 → 한 편 읽기 → 퀴즈'라는 핵심 흐름에서 이탈이 생길 만한 지점과 보완책은?

- 매일 계속 쓰게 만드는 장치(연속 일수, 리포트, 알림 문구 등)로 무엇을 더하면 좋을까?
- 지금 기능 중 데모에서는 빼는 게 나은 것, 반대로 꼭 있어야 하는데 없는 것은?
